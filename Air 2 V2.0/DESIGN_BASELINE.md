# 设计锁定基线

用户于 2026-09-21 明确：需求变更不等于重做设计，控制页必须沿用原 demo，报告也必须在原画布及设计语言内。

基线：同级源项目 `air2-h5-demo-mirror-20260814-copy-V4-mirror-20260825`。

- 沿用原 402 × 874 设计画布、整体缩放和移动端画布适配；新增页面不得独立建立 viewport 布局。
- 控制页由原 `v4Control` 渲染。保留原奶碗/硬件素材、液面与滴落动画、竖向档位 0–15、Both 联动、Speed、顶部导航与底部启停控件。
- 仅在原方案卡所在区域扩展已确认的左右流量、奶阵次数、峰值；吸乳方式入口遵循已确认的二级选择要求。
- 报告保留完整的信息结构、编辑及分享能力，视觉继承原记录页：`--font`、`#240f1b`、`#97002d`、浅粉渐变、24px 卡片、原导航尺寸及记录页衬线标题/奶量数字。
- 不能用新绘奶碗、横向滑块、新品牌色或新的全页排版替换原组件。用户明确批准重新设计前，本文件为后续修改约束。
- `pdcp-design-lock.css` 负责新增模块对齐；原样式与原组件优先复用。

- 不新增 oz / mL 切换入口；本轮所有奶量固定显示 oz，流量显示 oz/min。未确认的功能不得擅自添加。

- 方案选择页必须复用原 v4List 页面、Manual 卡片、Programs 列表与展开交互；仅增加同款 Auto Switch 卡片，不得替换为新弹层或新增 Speed 等控件。

- 佩戴检测复用原 fit-dock-r50 的酒红面板、泵素材、角度引导、进度条和 START 动效；只把检测项缩减为 Wearing angle 与 Battery，不新做检测卡片。

- 用户允许 Auto Switch 作为核心卖点单独强化：使用原酒红渐变、流量波形图标及简短功能说明；其他方案卡片与页面设计保持原版。

- 方案区沿用 Figma 157:3467 的白底、字体与圆角，但当前模式必须为只读状态，不呈现切换式 tabs。左右当前流量、奶阵次数、峰值必须直接展示，不能藏进 Details。紧凑排布保证左右与 Both 调档组件完整可见。

- 模拟流量参考用户 IMG_9124/9125 手绘图：大波段内连续小起伏，波段间才出现明显低谷。默认两个有限波段，不循环生成等高单峰；模拟事件单独预设，不根据小峰做固件分组推断。

- Auto Switch 专属选项采用紧凑白卡（86px）、左对齐原字体、小型文字选中标记；不使用粉色渐变、居中大标题、重复图标或通栏 Selected 按钮。

- 流量及峰值统一为 oz/min，显示值由内部 mL/min 除以 29.5735 换算，保留两位小数；报告曲线与导出一致。

- Auto Switch 右侧与原列表播放图标同位置同尺寸；只在 Auto 会话运行且未暂停时显示 Figma 158:3643 动态波形，移除 Selected 文字。

- Speed 固定 Slow/Regular/Fast 三档，采用 Figma 158:5793 图标与下方标签，不显示 1–5；内部值范围 1–3。

- 所有用户可见单位统一为美制液量 oz 体系：奶量、编辑、分阶段奶量、报告与导出用 oz，流量及峰值用 oz/min；内部 mL 计算仅作实现细节，输入 oz 换算后存储。不提供单位切换。

- 保留原 c36 温馨提示与提醒组件及动画：奶阵开始／结束、低电量、严重低电量和单侧满杯。提示由本期会话事件驱动，不恢复旧版奶阵结束自动结算逻辑。

- Triggers 增加 Wearing angle incorrect：暂停会话，复用 r72 气泡和 r97 奶碗调整动画；必须点 Wearing OK 才解除并显示恢复气泡、继续吸奶。异常期间禁止普通恢复按钮绕过佩戴确认。

- 模式图标使用 Figma 159:5883 / 159:5887 / 159:5895 导出的本地 SVG，保持 16px；模式变更时图标与名称横向交替，不改变卡片布局。

- 报告按 Figma 164:6300 作为底部半层呈现：原画布顶部留 62px，38px 顶部圆角，原底色、遮罩和上滑入场；保留报告内容、编辑与导出。

- Manual 区域按 Figma 164:6431 呈现 Stimulation / Expression / Mixed 三模式，使用本地原始素材、选中边框及运行波形。
- Auto 起始 Stimulation，奶阵来时 Expression，奶阵结束后 Mixed，后续 Expression / Mixed 交替。Mixed 连续 120 秒无新奶阵时提示准备结束，用户长按结束；暂停不累计，新奶阵重置等待。
- Hold to Finish 无描边，长按进度仍保留；Auto 卡片保持原尺寸，仅细化中性色底和柔和阴影。

- 控制方案区按方式分型：Auto 数据卡；Manual 复用 Figma 159:5865 三模式切换卡；Preset 按 Figma 115:6804 使用完整圆角卡片、已用／总时长、阶段条及右下 Auto Switch 开关；开启后进入现有 Auto Switch 方式。

- Auto 初始模式固定 Stimulation，未开始时的显示、新会话和切换入口均不继承 Manual 选中的模式；后续仍由奶阵事件驱动。

- 调档卡片按 Figma 170:6680：Level 0~15 标题、L/Both/R、170px 刻度轨道、渐变滑块和中性 Both 背景；保留 0–15 独立及联动拖动。

## 2026-09-22 评审批注
- 控制页数据与方案解耦，三种方式共用，默认折叠，仅展开实时流速和奶阵次数；左右列与奶量位置对齐。
- Deep Expression 只在 Auto 第一次奶阵峰值 0.5 mL/s 进入，降至 0.25 mL/s 退出。仍显示 Expression，只对水滴加呼吸动画；不是可选模式，不处理 Protection。
- 角度异常后暂停，通过 Simulate angle adjustment 模拟左右修正和水平线重合，显示角度到位后恢复；不调用震动。0°是演示对位目标，不替代设备的真实角度安全阈值。
- 满杯和最终结束先显示原提醒，再打开报告。
- 半层报告去除 Report/Recorded automatically，日期移至顶部；编辑铅笔放总量卡右上角；共享字段标题只保留奶阵次数、平均流速、峰值流速。
- 平均流速按原始单侧奶量/该侧有效时长计算，排除暂停；编辑奶量不改传感器统计。
- 每侧每个已识别奶阵集团记录一个主峰，在图上以虚线投影到时间轴；不是把每个小波算成奶阵。
